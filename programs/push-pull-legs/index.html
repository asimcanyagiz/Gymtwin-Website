Push Pull Legs workout plan

Push Pull Legs is an intermediate plan with 3 workout days of about 45 minutes each. Day 1, Push day: Barbell Bench Press, Incline Dumbbell Press, Dumbbell Overhead Press, Dumbbell Lateral Raise, and Cable Triceps Pushdown. Day 2, Pull day: Barbell Row, Wide Grip Lat Pulldown, Seated Cable Row, Cable Face Pull, and Dumbbell Hammer Curl. Day 3, Legs day: Leg Press, Dumbbell Lunge, Leg Extension, Lying Leg Curl Machine, and Standing Calf Raise.

Day 1: Push day

Chest, Shoulders, Arms

  1. Barbell Bench Press 4 sets × 6-8 reps · rest 2:30 Swap: Dumbbell Bench Press, Push Up
  2. Incline Dumbbell Press 4 sets × 8-10 reps · rest 1:30 Swap: Dumbbell Floor Press, Wide Push Up
  3. Dumbbell Overhead Press 4 sets × 8-10 reps · rest 1:30 Swap: Pike Push Up
  4. Dumbbell Lateral Raise 3 sets × 12-15 reps · rest 1:00 Swap: Prone T Raise
  5. Cable Triceps Pushdown 3 sets × 10-12 reps · rest 1:00 Swap: Dumbbell Triceps Extension, Bodyweight Triceps Extension

Day 2: Pull day

Back, Shoulders, Arms

  1. Barbell Row 4 sets × 6-8 reps · rest 2:30 Swap: Dumbbell Bent Over Row, Dumbbell Row
  2. Wide Grip Lat Pulldown 4 sets × 8-12 reps · rest 1:30 Swap: Dumbbell Pullover, Dumbbell Row
  3. Seated Cable Row 3 sets × 10-12 reps · rest 1:15 Swap: Dumbbell Kroc Row, Bird Dog Row
  4. Cable Face Pull 3 sets × 12-15 reps · rest 1:00 Swap: Dumbbell Rear Delt Raise, Prone T Raise
  5. Dumbbell Hammer Curl 3 sets × 10-12 reps · rest 1:00 Swap: Dumbbell Curl, Self Resisted Biceps Curl

Day 3: Legs day

Legs

  1. Leg Press 4 sets × 8-10 reps · rest 2:30 Swap: Dumbbell Squat, Bodyweight Squat
  2. Dumbbell Lunge 4 sets × 10-12 reps · rest 1:15 Swap: Reverse Lunge
  3. Leg Extension 3 sets × 12-15 reps · rest 1:00 Swap: Bodyweight Squat
  4. Lying Leg Curl Machine 3 sets × 10-12 reps · rest 1:00 Swap: Dumbbell Deadlift, Glute Bridge
  5. Standing Calf Raise 3 sets × 15-20 reps · rest 45 s

Equipment

You need barbell and plates, flat bench, dumbbells, adjustable bench, cable crossover, lat pulldown, seated cable row, leg press, leg extension, and leg curl. Each exercise lists a swap if your gym doesn't have the main one.
