Beginner · 3 days · about 45 min

Machine Starter workout plan

Machine Starter is a beginner plan with 3 workout days of about 45 minutes each. Day 1, machines a: Leg Press, Chest Press Machine, Wide Grip Lat Pulldown, Leg Extension, Lying Leg Curl Machine, and Cable Crunch. Day 2, machines b: Leg Press, Chest Fly Machine, Seated Cable Row, Cable Lateral Raise, Lying Leg Curl Machine, and Cable Triceps Pushdown. Day 3, machines c: Leg Extension, Chest Press Machine, Wide Grip Lat Pulldown, Cable Face Pull, Cable Curl, and Cable Wood Chop.

Day 1: Machines A

Full Body

  1. Leg Press 3 sets × 10-12 reps · rest 1:30 Swap: Dumbbell Squat, Bodyweight Squat
  2. Chest Press Machine 3 sets × 10-12 reps · rest 1:30 Swap: Dumbbell Bench Press, Push Up
  3. Wide Grip Lat Pulldown 3 sets × 10-12 reps · rest 1:30 Swap: Dumbbell Pullover, Dumbbell Row
  4. Leg Extension 2 sets × 12-15 reps · rest 1:00 Swap: Dumbbell Lunge, Bodyweight Squat
  5. Lying Leg Curl Machine 2 sets × 12-15 reps · rest 1:00 Swap: Dumbbell Deadlift, Glute Bridge
  6. Cable Crunch 3 sets × 12-15 reps · rest 45 s Swap: Crunch

Day 2: Machines B

Full Body

  1. Leg Press 3 sets × 12-15 reps · rest 1:15 Swap: Dumbbell Squat, Bodyweight Squat
  2. Chest Fly Machine 3 sets × 12-15 reps · rest 1:00 Swap: Dumbbell Fly, Push Up
  3. Seated Cable Row 3 sets × 10-12 reps · rest 1:15 Swap: Dumbbell Row, Bird Dog Row
  4. Cable Lateral Raise 2 sets × 12-15 reps · rest 1:00 Swap: Dumbbell Lateral Raise, Prone T Raise
  5. Lying Leg Curl Machine 3 sets × 10-12 reps · rest 1:00 Swap: Dumbbell Deadlift, Glute Bridge
  6. Cable Triceps Pushdown 2 sets × 10-12 reps · rest 1:00 Swap: Dumbbell Triceps Extension, Bodyweight Triceps Extension

Day 3: Machines C

Full Body

  1. Leg Extension 3 sets × 12-15 reps · rest 1:00 Swap: Dumbbell Lunge, Bodyweight Squat
  2. Chest Press Machine 3 sets × 8-12 reps · rest 1:30 Swap: Dumbbell Bench Press, Push Up
  3. Wide Grip Lat Pulldown 3 sets × 8-12 reps · rest 1:30 Swap: Dumbbell Pullover, Dumbbell Row
  4. Cable Face Pull 3 sets × 12-15 reps · rest 1:00 Swap: Dumbbell Rear Delt Raise, Prone T Raise
  5. Cable Curl 2 sets × 10-12 reps · rest 1:00 Swap: Dumbbell Curl, Self Resisted Biceps Curl
  6. Cable Wood Chop 3 sets × 10-12 reps · rest 45 s Swap: Dumbbell Russian Twist, Crunch

Equipment

You need leg press, chest press machine, lat pulldown, leg extension, leg curl, cable crossover, pec deck, and seated cable row. Each exercise lists a swap if your gym doesn't have the main one.
