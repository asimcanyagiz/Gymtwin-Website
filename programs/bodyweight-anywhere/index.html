Bodyweight Anywhere workout plan

Bodyweight Anywhere is an all-levels plan with 3 workout days of about 30 minutes each. Day 1, bodyweight a: Bodyweight Squat, Push Up, Superman, Reverse Lunge, Pike Push Up, and Plank. Day 2, bodyweight b: Reverse Lunge, Wide Push Up, Prone Pull Down, Single Leg Glute Bridge, Bodyweight Triceps Extension, and Dead Bug. Day 3, bodyweight c: Glute Bridge, Diamond Push Up, Reverse Snow Angel, Standing Calf Raise, Mountain Climber, and Crunch.

Day 1: Bodyweight A

Full Body

  1. Bodyweight Squat 3 sets × 12-15 reps · rest 45 s
  2. Push Up 3 sets × 8-12 reps · rest 45 s
  3. Superman 3 sets × 10-12 reps · rest 45 s
  4. Reverse Lunge 3 sets × 10-12 reps · rest 45 s
  5. Pike Push Up 3 sets × 6-10 reps · rest 45 s
  6. Plank 3 sets × 20-30 reps · rest 45 s

Day 2: Bodyweight B

Full Body

  1. Reverse Lunge 3 sets × 10-12 reps · rest 45 s
  2. Wide Push Up 3 sets × 8-12 reps · rest 45 s
  3. Prone Pull Down 3 sets × 10-12 reps · rest 45 s
  4. Single Leg Glute Bridge 3 sets × 8-10 reps · rest 45 s
  5. Bodyweight Triceps Extension 2 sets × 8-12 reps · rest 45 s
  6. Dead Bug 3 sets × 10-12 reps · rest 45 s

Day 3: Bodyweight C

Full Body

  1. Glute Bridge 3 sets × 12-15 reps · rest 45 s
  2. Diamond Push Up 3 sets × 6-10 reps · rest 45 s
  3. Reverse Snow Angel 3 sets × 10-12 reps · rest 45 s
  4. Standing Calf Raise 3 sets × 15-20 reps · rest 45 s
  5. Mountain Climber 3 sets × 20-30 reps · rest 45 s
  6. Crunch 3 sets × 12-15 reps · rest 45 s

Equipment

No equipment, just your body weight. Each exercise lists a swap if your gym doesn't have the main one.

Run this plan in Gym Twin

Bodyweight Anywhere is built into the app. Pick your training days, start a day as a live workout with a rest timer, and keep your gym streak going.
