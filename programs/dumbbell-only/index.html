Dumbbell Only workout plan

Dumbbell Only is an all-levels plan with 3 workout days of about 45 minutes each. Day 1, dumbbell a: Dumbbell Squat, Dumbbell Bench Press, Dumbbell Row, Dumbbell Overhead Press, Dumbbell Curl, and Dumbbell Russian Twist. Day 2, dumbbell b: Dumbbell Lunge, Incline Dumbbell Press, Dumbbell Bent Over Row, Dumbbell Lateral Raise, Dumbbell Triceps Extension, and Dumbbell Crunch. Day 3, dumbbell c: Dumbbell Deadlift, Dumbbell Floor Press, Dumbbell Pullover, Dumbbell Rear Delt Raise, Dumbbell Hammer Curl, and Dumbbell Hip Thrust.

Day 1: Dumbbell A

Full Body

  1. Dumbbell Squat 3 sets × 10-12 reps · rest 1:15 Swap: Bodyweight Squat
  2. Dumbbell Bench Press 3 sets × 8-12 reps · rest 1:15 Swap: Dumbbell Floor Press, Push Up
  3. Dumbbell Row 3 sets × 10-12 reps · rest 1:15 Swap: Dumbbell Bent Over Row, Bird Dog Row
  4. Dumbbell Overhead Press 3 sets × 8-12 reps · rest 1:15 Swap: Pike Push Up
  5. Dumbbell Curl 2 sets × 10-12 reps · rest 1:00 Swap: Self Resisted Biceps Curl
  6. Dumbbell Russian Twist 3 sets × 12-20 reps · rest 45 s Swap: Dead Bug, Crunch

Day 2: Dumbbell B

Full Body

  1. Dumbbell Lunge 3 sets × 10-12 reps · rest 1:15 Swap: Reverse Lunge
  2. Incline Dumbbell Press 3 sets × 8-12 reps · rest 1:15 Swap: Dumbbell Floor Press, Push Up
  3. Dumbbell Bent Over Row 3 sets × 10-12 reps · rest 1:15 Swap: Dumbbell Row, Bird Dog Row
  4. Dumbbell Lateral Raise 3 sets × 12-15 reps · rest 1:00 Swap: Prone T Raise
  5. Dumbbell Triceps Extension 2 sets × 10-12 reps · rest 1:00 Swap: Bodyweight Triceps Extension, Diamond Push Up
  6. Dumbbell Crunch 3 sets × 12-15 reps · rest 45 s Swap: Crunch

Day 3: Dumbbell C

Full Body

  1. Dumbbell Deadlift 3 sets × 8-10 reps · rest 1:30 Swap: Glute Bridge
  2. Dumbbell Floor Press 3 sets × 10-12 reps · rest 1:15 Swap: Push Up
  3. Dumbbell Pullover 3 sets × 10-12 reps · rest 1:15 Swap: Dumbbell Row, Superman
  4. Dumbbell Rear Delt Raise 3 sets × 12-15 reps · rest 1:00 Swap: Prone Y Raise
  5. Dumbbell Hammer Curl 2 sets × 10-12 reps · rest 1:00 Swap: Self Resisted Biceps Curl
  6. Dumbbell Hip Thrust 3 sets × 10-12 reps · rest 1:00 Swap: Single Leg Glute Bridge, Glute Bridge

Equipment

You need dumbbells, flat bench, and adjustable bench. Each exercise lists a swap if your gym doesn't have the main one.

Run this plan in Gym Twin

Dumbbell Only is built into the app. Pick your training days, start a day as a live workout with a rest timer, and keep your gym streak going.
